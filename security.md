## 🎨 Beautiful Code. Stunning Designs.

**HTML Website Templates** is a curated, open-source repository of high-quality, fully responsive website templates designed to jumpstart your next web project. 

Whether you are a freelance developer building a portfolio, a startup launching a landing page, or a student learning web design, this collection has everything you need. Every template is built from scratch using **pure HTML5, modern CSS (Flexbox/Grid), and minimal JavaScript**, ensuring they are incredibly fast, lightweight, and easy to customize.

Forget about heavy frameworks and bloated page builders. These templates give you clean, semantic markup that you actually own. Just download the ZIP, open it in VS Code, and you are ready to deploy to Netlify or Vercel in minutes.

> 💡 **Why use these templates?** Because starting from a blank screen is hard. Get a beautiful, accessible, and performant foundation so you can focus on your content.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Browse the collection
Click the **Live Preview** button at the top to see all templates hosted on GitHub Pages.

### 2️⃣ Download your favorite
Hit the **Get Templates** button to download the repository as a ZIP file.

### 3️⃣ Customize
Open the `index.html` file in your code editor, replace the text and images, and save.

## ❓ Frequently Asked Questions

<details>
<summary><b>Can I use these templates commercially?</b></summary>

Yes. All templates are released under the **MIT License**. You can use them for client work, startups, or personal projects without paying a dime. Attribution is appreciated but not required.
</details>

<details>
<summary><b>Do I need to know how to code?</b></summary>

Basic knowledge of HTML is helpful. You need to know how to open a file, find the text, and replace it. If you know CSS, you can completely transform the designs.
</details>

<details>
<summary><b>Do these templates work with React or Vue?</b></summary>

Yes! You can easily convert the static HTML into JSX or Vue components. However, the templates are designed to be used as static sites for maximum performance.
</details>

<details>
<summary><b>Are there dark mode versions?</b></summary>

Most templates include a built-in CSS variable for dark mode, and some come with a toggle switch implemented in vanilla JavaScript.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include the name of the template and a screenshot of the visual bug you found.
</details>
